# blinkit-sales-dashboard
Interactive Power BI dashboard for analyzing Blinkit grocery sales, outlet performance, product categories, customer ratings, and sales trends using Power BI, DAX, and Power Query.
The Blinkit Sales Dashboard is an interactive Power BI project designed to analyze grocery sales performance across different outlet types, outlet sizes, locations, and product categories. The dashboard provides valuable business insights through dynamic KPIs and visualizations, helping stakeholders monitor sales, customer ratings, inventory, and outlet performance. It enables users to identify sales trends, compare outlet performance, and make data-driven decisions.
Features
Total Sales, Average Sales, Number of Items, and Average Rating KPIs
Sales analysis by Outlet Type
Outlet Location and Outlet Size comparison
Sales trend by Establishment Year
Product Category and Fat Content analysis
Interactive slicers for Outlet Type, Size, and Item Type
Clean and responsive dashboard design
